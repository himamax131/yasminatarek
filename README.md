# Yasmina Tarek — موقع حجز المواعيد (تحديث عالمي + عربون ثابت 200 ج)

## التحديثات الجديدة
- **عربون ثابت 200 جنيه** لكل حجز. يظهر تلقائي في قاعدة البيانات (Firestore) بحالة **pending**.
- بعد التحويل لازم العميل يبعت **إثبات الدفع (صورة التحويل) على واتساب**.
- في **لوحة الحسابات** (Finance) الحجز يظهر تلقائي مع:
  - الإجمالي (سعر الباكدج)
  - العربون 200
  - المتبقي = الإجمالي − 200
  - الحالة: قيد الانتظار → الأدمن يدوس "✅ وصل" أو يحدّث العربون فيتحوّل لـ partial / paid ويحسب في الدخل.
- **أسعار الباكدجات** (تظهر في الحسابات فقط للأدمن):
  - سواريه: 800 | سواريه VIP: 1000
  - خطوبة: 1400 | خطوبة VIP: 1700
  - كتب كتاب: 1400 | كتب كتاب VIP: 1700
  - حنة: 1400 | حنة VIP: 1700
  - زفاف: 4000
  - كاش حجاب (سواريه): 350 | (خطوبة/حنة/كتب كتاب): 600 | (زفاف): 1000
  - حجاب كامل: مع الباكدج
- إصلاح حفظ الحجوزات في Firestore (إضافة الحقول المطلوبة: deposit / total / remaining / status).
- تحديث قواعد Firestore لدعم الحقول المالية وتأكيد الاستلام من الأدمن فقط.

## بيانات الأدمن
اسم المستخدم `yt` وكلمة المرور `1234` (من `CONFIG.admin`).

## تجهيز Firebase (مرة واحدة)
1. **Authentication** ← Sign-in method ← فعّلي **Email/Password**.
2. **Authentication** ← Users ← **Add user**: الإيميل `admin@yasmina-tarek.app` والباسورد `YT-1234-Yasmina`
   (لو غيّرتي `CONFIG.admin.pass` غيّري باسورد اليوزر لـ `YT-<الباسورد الجديد>-Yasmina`).
3. **Firestore Database** ← **Rules** ← الصقي محتوى `firestore.rules` ← **Publish**.
