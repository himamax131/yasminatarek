# Yasmina Tarek Makeup Booking

## تم تعديل النسخة
- اللوجو المستخدم هو اللوجو المرسل من صاحبة الموقع.
- تصميم Responsive جديد للديسكتوب والموبايل.
- ألوان فخمة أسود + ذهبي + روز مناسبة للوجو.
- اختيار الخدمة.
- اختيار التاريخ.
- اختيار الساعة من 10:00 صباحًا حتى 7:00 مساءً، ساعة بساعة.
- اختيار مكان الحجز: السنتر أو عنوان منزل.
- عند اختيار عنوان منزل يظهر حقل العنوان ويصبح مطلوبًا.
- رقم الدفع: `01094015949` لفودافون كاش وInstaPay.
- واتساب: `01016357871`.
- تأكيد الحجز يفتح رسالة واتساب جاهزة بكل بيانات الحجز.
- Firestore يستخدم transaction لمنع حجز نفس الساعة مرتين في نفس الوقت.

## ربط Firebase الموجود عندك
القواعد التي أرسلتها موجودة في `firestore.rules`.

الذي ينقص فقط هو **Firebase Web App Config** الخاص بمشروعك، لأنه غير موجود في الملف المرسل.

من Firebase Console:
1. افتحي المشروع.
2. Project settings.
3. في Your apps اختاري Web app أو أضيفي Web App.
4. انسخي كود `firebaseConfig`.
5. ضعي القيم داخل `index.html` عند `CONFIG.firebase`.

مثال الشكل المطلوب:
```js
firebase:{
  apiKey:"...",
  authDomain:"...",
  projectId:"...",
  storageBucket:"...",
  messagingSenderId:"...",
  appId:"..."
}
```

## قاعدة البيانات
سيتم إنشاء/استخدام مجموعتين:
- `slots` — لحجز الموعد ومنع التكرار.
- `bookings` — لحفظ بيانات الحجز كاملة، ومنها الاسم والموبايل والخدمة والتاريخ والساعة والمكان والعنوان والملاحظات.

## ملاحظة أمنية مهمة
القواعد المرسلة حاليًا:
`allow read, write: if true;`
تعني أن أي شخص يمكنه القراءة والكتابة على قاعدة البيانات. هي مناسبة للتجربة، لكن لا يُنصح باستخدامها كما هي على موقع حقيقي. بعد التأكد من تشغيل الموقع، الأفضل تأمين القواعد.
