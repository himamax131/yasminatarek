# Yasmina Tarek — موقع حجز المواعيد (تصميم داشبورد فاخر)

## التصميم الجديد
- واجهة داشبورد كريمي + ذهبي + سايدبار أسود (مطابقة للصورة المطلوبة)
- فورم حجز نظيف: اسم، هاتف، باكدج، تاريخ، وقت، ديبوزت ثابت 200 ج، مكان، ملاحظات
- سايدبار: حجز جديد · الأيام المحجوزة · لوحة الأدمن (مواعيد العملاء + الحسابات)

## العربون والحسابات
- **عربون ثابت 200 جنيه** لكل حجز
- يظهر في Firestore بحالة `pending`
- بعد التحويل: العميل يبعت **صورة الإثبات على واتساب**
- الأدمن من لوحة الحسابات يدوس **✅ وصل** فيتحوّل لـ partial ويُحسب في الدخل
