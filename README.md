# Yasmina Tarek — موقع حجز المواعيد

## المميزات
- **الصفحة الرئيسية**: هيرو بستايل ناعم (لوجو دائري + أماكن متاحة + أزرار حجز وأسعار)
- **فورم الحجز**: عربون ثابت 200 ج + مكان السنتر/المنزل (مع تنبيه Out Door)
- **حالات الحجز**: قيد الانتظار → تم الاستلام (زر استلام) → تم الانتهاء (بعد تاريخ الموعد)
- **الحسابات**: إحصائيات (إجمالي / عملاء / عربون / متبقي / مبيعات / مصروفات) + تعديل + حذف نهائي
- **المشتريات (ماتريال)**: إضافة منتجات ومصروفات تظهر في الحسابات
- **حذف الحجوزات**: من مواعيد العملاء أو الحسابات — حذف نهائي من الموقع وقاعدة البيانات
