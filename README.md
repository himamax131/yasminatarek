# Yasmina Tarek — موقع حجز المواعيد

- **عربي / English** من زرار 🌐 فوق (بيفتكر اختيارك). الرسالة اللي بتروح لياسمين على واتساب دايمًا بالعربي.
- **8 ألوان** تختاري منهم من زرار 🎨 فوق (ذهبي، روز جولد، فوشيا، بنفسجي، أزرق ليلي، زمردي، فضي، غروب) — واللوجو والأنيميشن بياخدوا اللون.
- **خطوط جديدة**: Cairo + Reem Kufi للعربي، وPlayfair Display + Poppins للإنجليزي.
- **رقم فودافون كاش جديد** (01015043260) والإنستا زي ما هو. تقدري تغيّريهم من `CONFIG.payments` في `index.html`.
- **الحجز لأي يوم في السنة**: تقويم كامل بأنيميشن، شريط شهور بتسحبيه، وأسهم للتنقل. (سنة قدام من النهاردة، وتتغير من `CONFIG.maxDaysAhead`).
- **حجوزات الشهور** (الكارت اللي على الشمال): افتحيه بكلمة المرور، اختاري السنة والشهر (1 لـ 12) وهتشوفي كل الحجوزات: الاسم والموبايل والخدمة والمكان، وزرار اتصال / واتساب / تعديل / إلغاء.
- **اللوجو**: لو هتغيّريه بنفسك، حطي الصورة جنب `index.html` واكتبي اسمها في `CONFIG.customLogo` (مثال: `"my-logo.png"`) وهيتغيّر في كل مكان.

## بيانات الأدمن
اسم المستخدم `yt` وكلمة المرور `1234` (من `CONFIG.admin`). مطلوبة عند الضغط على أي ميعاد "محجوز" وعند فتح كارت حجوزات الشهور.

## تجهيز Firebase (لازم مرة واحدة)
علشان الأدمن يقدر يقرا الحجوزات ويلغي ويعدّل من غير ما بيانات العملاء تبقى مكشوفة للناس:
1. **Authentication** ← Get started ← Sign-in method ← فعّلي **Email/Password**.
2. **Authentication** ← Users ← **Add user**:
   - Email: `admin@yasmina-tarek.app`
   - Password: `YT-1234-Yasmina`
   (لو غيّرتي كلمة المرور في `CONFIG.admin.pass` لازم تغيّري باسورد اليوزر ده لـ `YT-<الباسورد الجديد>-Yasmina`).
3. **Firestore Database** ← **Rules** ← امسحي القديم والصقي محتوى `firestore.rules` ← **Publish**.
لو لسه مجهزتيش الخطوات دي، هتظهر رسالة توضح إن حساب الأدمن مش متجهز.

## ملاحظة
الحجوزات القديمة (قبل التحديث) بتظهر في الكارت عادي، ولو اتنقلت أو اتلغت من الموقع، بياناتها في Firebase Console (`bookings`) ممكن تحتاج تتعدل يدويًا.
