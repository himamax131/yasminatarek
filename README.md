# Yasmina Tarek — موقع حجز المواعيد (نسخة جديدة ✨)

## إيه الجديد
- **لوجو جديد**: مونوجرام **YT** ذهبي مع زهرة ياسمين 🌼 (الملف `logo.svg` + كل الأيقونات في `icons/`).
- **تصميم جديد بالكامل**: أسود + ذهبي + روز، أنيميشن (شاشة افتتاحية بترسم اللوجو، بتلات ياسمين وغبار ذهبي في الخلفية، ظهور تدريجي مع السكرول، تأثيرات على الأزرار والكروت، كونفيتي بعد الحجز).
- **خطوط جديدة**: Aref Ruqaa للعناوين + El Messiri للنصوص + Great Vibes / Cinzel للاسم بالإنجليزي.
- **تعديل / إلغاء الحجز**: اضغطي على أي ميعاد مكتوب عليه "محجوز" ← تظهر نافذة دخول الأدمن.
  - اسم المستخدم: `yt`
  - كلمة المرور: `1234`
  - بعد الدخول: **تعديل الحجز** (نقل ليوم/ساعة تانية أو تغيير الخدمة) أو **إلغاء الحجز** (الميعاد بيرجع متاح فورًا).
  - لتغيير بيانات الدخول: عدّلي `CONFIG.admin` في أول السكريبت داخل `index.html`.

## مهم جدًا: انشري القواعد الجديدة
علشان الإلغاء والتعديل يشتغلوا لازم تحدّثي قواعد Firestore:
1. افتحي Firebase Console ← Firestore Database ← **Rules**.
2. امسحي القديم والصقي محتوى ملف `firestore.rules` الجديد.
3. اضغطي **Publish**.

## ملاحظة أمنية
كلمة المرور بتتراجع داخل كود الصفحة، يعني حد عنده خبرة تقني ممكن يوصل للإلغاء بدون ما يعرفها. مناسبة للاستخدام العادي، ولو عايزة حماية حقيقية الأفضل نضيف Firebase Authentication للأدمن.

## الحجوزات القديمة
الحجوزات اللي اتعملت قبل التحديث ممكن تتلغى وتتنقل من الموقع عادي، لكن بياناتها في Firebase Console (مجموعة `bookings`) مش بتتحدث تلقائيًا — امسحيها أو عدّليها من هناك.

## الملفات
`index.html` الموقع · `firestore.rules` القواعد · `manifest.webmanifest` + `sw.js` للتطبيق · `icons/` + `logo-full-*.png` + `logo.svg` اللوجو.
